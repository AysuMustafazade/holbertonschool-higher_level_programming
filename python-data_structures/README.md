# Python - Data Structures: Lists, Tuples

## Description
This project focuses on the fundamental data structures in Python: Lists and Tuples. It covers how to manipulate these structures, use built-in methods, and understand the differences between mutable and immutable objects. By completing these tasks, you'll learn how to store, access, and modify data efficiently in Python.

## Learning Objectives
* How to use lists and what are their most common methods.
* How to use lists as stacks and queues.
* List comprehensions and why they are used.
* What are tuples and how to use them.
* When to use tuples versus lists.
* What is a sequence and what are the most common sequence types.
* How to use the `del` statement.

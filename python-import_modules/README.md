# Python - import & modules

## Description
This project covers the basics of importing functions and variables from other files, creating modules, and using built-in Python modules like `sys`. It emphasizes the importance of writing clean, modular code and understanding the execution environment of Python scripts.

## Learning Objectives
* How to import functions from other files.
* How to use the `if __name__ == "__main__":` idiom to prevent code from executing when imported.
* How to use command-line arguments using `sys.argv`.
* How to use the `dir()` function to list definitions in a module.
